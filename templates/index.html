    Mot de passe d'application

    Depuis 2022, Gmail, Outlook et Yahoo refusent votre mot de passe habituel pour les applications externes. Il faut créer un mot de passe d'application dédié.

    Gmail

    1. Activez la validation en deux étapes sur votre compte Google.
    2. Ouvrez myaccount.google.com/apppasswords.
    3. Créez un mot de passe pour « Autre (nom personnalisé) ».
    4. Copiez les 16 caractères ici, sans les espaces.

    Outlook / Microsoft 365

    1. Serveur smtp.office365.com, port 587.
    2. Créez un mot de passe d'application dans la sécurité du compte (la validation en deux étapes doit être active).

    Yahoo

    1. Serveur smtp.mail.yahoo.com, port 587.
    2. Rubrique « Sécurité du compte » → « Générer un mot de passe d'application ».

    Un envoi vers plus de 50 destinataires d'un coup peut être bloqué par votre fournisseur. L'application espace automatiquement les envois d'une seconde.
